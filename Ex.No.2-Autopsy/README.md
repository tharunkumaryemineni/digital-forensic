# Ex.No.5 - Using Autopsy to Create a Case and Import Evidence

## Aim

To create a new forensic case in **Autopsy**, import digital evidence, perform forensic analysis using ingest modules, and generate a forensic investigation report.

---

## Objective

- Learn how to create a new case in Autopsy.
- Import forensic image files as evidence.
- Configure ingest modules for analysis.
- Examine digital artifacts.
- Generate forensic investigation reports.

---

## Software Required

- Autopsy Digital Forensics Platform
- Windows/Linux/macOS
- Sample Evidence Files (.E01, .dd, .raw)

---

## About Autopsy

Autopsy is an **open-source digital forensics platform** used to analyze digital evidence from storage devices and forensic image files. It provides features such as keyword searching, timeline analysis, hash analysis, file recovery, and report generation. :contentReference[oaicite:0]{index=0}

---

# Procedure

## Step 1: Install Autopsy

1. Download Autopsy from the official website.
2. Install the software according to your operating system.
3. Launch the application.

---

## Step 2: Create a New Case

1. Open **Autopsy**.
2. Click **New Case**.
3. Enter:
   - Case Name
   - Case Location
   - Case Number
   - Examiner Name
4. Click **Next**.

---

## Step 3: Add a Data Source

1. Choose **Add Data Source**.
2. Select one of the following:
   - Disk Image
   - Local Disk
   - Logical Files
   - Directory
3. Browse and select the forensic image file (.E01, .dd, .raw).
4. Click **Next**. :contentReference[oaicite:1]{index=1}

---

## Step 4: Configure Ingest Modules

Enable the required analysis modules, such as:

- File Type Identification
- Keyword Search
- Hash Lookup
- Recent Activity
- File Metadata Analysis

Click **Next** to begin processing.

---

## Step 5: Analyze the Evidence

Autopsy processes the evidence and categorizes artifacts automatically.

Available artifacts include:

- File System
- Web History
- Email
- Metadata
- Communication Records

Use the **Tree Viewer** to navigate through the collected evidence. :contentReference[oaicite:2]{index=2}

---

## Step 6: Detailed Investigation

### Keyword Search

- Search for specific keywords.
- Use predefined or custom keyword lists.

### File Analysis

- Browse folders and files.
- View or export files.

### Timeline Analysis

- Analyze events based on timestamps.
- Track user activities chronologically.

### Hash Analysis

- Compare file hashes with known hash databases.
- Identify trusted or suspicious files. :contentReference[oaicite:3]{index=3}

---

## Step 7: Generate Report

1. Click **Generate Report**.
2. Choose the report format:
   - HTML
   - CSV
   - Excel
3. Select the artifacts to include.
4. Export the report.

Review the report before saving or printing. :contentReference[oaicite:4]{index=4}

---

## Step 8: Close the Case

1. Close the current case.
2. Archive the case files and reports for future reference. :contentReference[oaicite:5]{index=5}

---

## Advanced Features

Autopsy also supports:

- Custom Ingest Modules
- Multi-user Collaboration
- Additional Analysis Plugins :contentReference[oaicite:6]{index=6}

---

## Result

Successfully created a forensic case in **Autopsy**, imported digital evidence, analyzed the acquired artifacts, and generated a forensic investigation report.

---

## Conclusion

Autopsy provides an efficient and user-friendly environment for digital forensic investigations. It enables investigators to analyze forensic images, recover evidence, examine artifacts, perform keyword and timeline analysis, verify file integrity using hashes, and generate comprehensive reports.
