# 🔍 Digital Forensics – Experiment No. 6

## Use Sleuth Kit to Analyze Digital Evidence

---

## 📌 Aim

To use **The Sleuth Kit (TSK)** to analyze disk images and recover digital evidence.

---

## 📖 Description

The **Sleuth Kit (TSK)** is a collection of command-line tools used to analyze disk images and recover digital evidence.

It provides different tools for:

- Analyzing file systems
- Viewing partitions
- Listing files and directories
- Recovering deleted files
- Examining file metadata
- Creating forensic timelines
- Generating investigation reports

---

## 🛠️ Requirements

- Windows Operating System
- Sleuth Kit
- Command Prompt
- FTK Imager / `dd`
- OSFMount (Optional)
- Disk Image Files
